# 台中，隨心吃。

手機友善的台中美食、天氣與交通手冊。根目錄 `index.html` 為可直接部署的單一檔案，已加入瀏覽密碼入口。

## 公開版本內容

- 50個公開店家、13種類別，支援搜尋、分類、瀏覽器本機收藏及各店地圖／導航。
- 台中市區概覽地圖；已移除與個人帳戶相關的自訂地圖及共享清單網址。
- 機場往返具體時間表、入境與報到步驟、公車上下車位置及票價，均在加密內容內，需解鎖後查看；未另上傳明文行程檔。未包含姓名、聯絡資料、艙等或航班編號。
- 台中固定市區座標的當前天氣模式資料及未來5日預報：溫度、體感、濕度、風速、天氣狀態、降雨機率。開啟時取得，可手動更新；頁面顯示期間每15分鐘更新。失敗時提供提示及氣象署連結。不使用裝置定位。

## 瀏覽入口

頁面使用 Web Crypto PBKDF2-SHA256（210,000次）及 AES-256-GCM 於瀏覽器解鎖，密碼不以明文寫入檔案，也不傳送到伺服器；重新整理及關閉後需再次輸入。公開部署檔只包含加密內容，未另附可繞過入口的明文內容檔。

這是靜態頁面上的簡易瀏覽限制，**不等於伺服器身分驗證**。簡單密碼仍可能被離線猜測，取得密碼者亦可複製解鎖內容。請勿使用此頁存放敏感資料。密碼由擁有者另行提供，請勿寫入公開README、issue或commit。

## 部署

將根目錄 `index.html` 以 HTTPS 靜態託管（如 GitHub Pages）提供即可；本機開發可使用 localhost。無需套件、建置或API金鑰。地圖、天氣及導航需要網絡。收藏保存在當前瀏覽器，無法跨裝置同步。網頁及公開repo的存取權限為不同層次。

## 機場交通細節

加密手冊已加入去程及回程的具體行程時間、500號官方指定站間成人票價、非市民電子票證與現金差別、機場公車2號月台、B1計程車位置、回程候車站及車輛方向、叫車備案與入境／報到步驟。公車規劃時間不冒充已確認班次；官方固定分鐘班表未能核實，須當天查官方即時動態。的士提供正式費率與預算，不把估算寫成精確報價。
