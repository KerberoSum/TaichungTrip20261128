# 台中，隨心吃。

手機友善的台中美食、天氣與交通手冊。根目錄 `index.html` 為可直接部署的單一檔案，已加入瀏覽密碼入口。

## 公開版本內容

- 50個公開店家、13種類別，支援搜尋、分類、瀏覽器本機收藏及各店地圖／導航。
- 依擁有者要求恢復原本 Google My Maps 的內嵌標記地圖及全螢幕連結，含50間美食及10個景點；嵌入地圖會顯示 Google 提供的地圖標題與作者公開資訊。
- 機場往返具體時間表、入境與報到步驟、公車上下車位置及票價，均在加密內容內，需解鎖後查看；未另上傳明文行程檔。未包含姓名、聯絡資料、艙等或航班編號。
- 台中固定市區座標的2026年11月28日逐小時預報，僅顯示09:00–21:00行程時段：溫度、體感、天氣狀態、降雨機率與風速。開啟時取得，可手動更新；頁面顯示期間每15分鐘更新。失敗時明示，不以其他日期代替。不使用裝置定位。

## 瀏覽入口

頁面使用 Web Crypto PBKDF2-SHA256（210,000次）及 AES-256-GCM 於瀏覽器解鎖，密碼不以明文寫入檔案，也不傳送到伺服器；重新整理及關閉後需再次輸入。公開部署檔只包含加密內容，未另附可繞過入口的明文內容檔。

這是靜態頁面上的簡易瀏覽限制，**不等於伺服器身分驗證**。簡單密碼仍可能被離線猜測，取得密碼者亦可複製解鎖內容。請勿使用此頁存放敏感資料。密碼由擁有者另行提供，請勿寫入公開README、issue或commit。

## 部署

將根目錄 `index.html` 以 HTTPS 靜態託管（如 GitHub Pages）提供即可；本機開發可使用 localhost。無需套件、建置或API金鑰。地圖、天氣及導航需要網絡。收藏保存在當前瀏覽器，無法跨裝置同步。網頁及公開repo的存取權限為不同層次。

## 機場交通細節

加密手冊已加入去程及回程的具體行程時間、500號官方指定站間成人票價、非市民電子票證與現金差別、機場公車2號月台、B1計程車位置、回程候車站及車輛方向、叫車備案與入境／報到步驟。公車規劃時間不冒充已確認班次；官方固定分鐘班表未能核實，須當天查官方即時動態。的士提供正式費率與預算，不把估算寫成精確報價。

## 路況查看與時間提醒

解鎖後可選擇機場往返方向、市區候選店家及交通方式，開啟 Google Maps 即時車程、台中官方道路速率／CCTV及公車動態。Google Maps 車程須手動查閱及輸入；本頁沒有 Google Routes API 金鑰，不會自動讀取路線延誤。輸入車程及額外緩衝後，可計算市區抵達時間或回程出發時間；更換路線會清除舊車程，記錄超過15分鐘提示重查。

頁面顯示期間每2分鐘嘗試取得警廣公開路況通報，以台中地區及機場走廊關鍵字篩選可能相關事件；不是實際導航路線交集分析。顯示取得時間、來源時間及較舊／已排除通報。來源連線失敗或資料過期會明示無法確認，不會以沒有通報判定道路暢通。初次瀏覽器測試中警廣來源連線逾時，當時未能驗證即時通報成功載入；請使用官方路況圖與 Maps 備援。關閉、上鎖或切至背景後不持續監看，沒有背景通知。沒有新增伺服器排程、裝置定位或 API 金鑰。

## 緊湊版面與景點標記

整體縮小字級、間距及卡片，桌面四欄、手機兩欄（極窄畫面一欄）；景點詳細提醒可展開。地圖移到首頁介紹之後，直接使用原本 My Maps 的標記版本，另提供全螢幕入口。觀光候選增至10處：審計新村、草悟道、臺中公園、綠川、國家歌劇院、柳川、秋紅谷、臺中驛鐵道文化園區、中央公園、一中商圈。新增景點已同步到原地圖的獨立圖層，統一樣式並標示名稱；各地點以（景點）開頭。停留時間為規劃估算，開放與活動依當日官方公告。
